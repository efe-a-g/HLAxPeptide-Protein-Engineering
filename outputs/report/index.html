Do protein foundation models help predict peptide-HLA stability?

An ablation study on 28,166 peptide-HLA class I half-life measurements (Rasmussen et al. 2016). The question asked was are they useful for this problem — not prove they are useful. This page reports what the experiments actually showed, including where the foundation models lose.

Verdict

The noise floor comes first

No difference below this threshold counts as a result. The published baseline script seeds NumPy but never calls torch.manual_seed, so its --seed fixes the data split while leaving weight initialisation and batch shuffling free. Repeat runs at a fixed seed and fixed split therefore still disagree — and that disagreement is the floor every comparison on this page must clear.

Which part helps?

The Boltz-2 embeddings are per-allele: 75 distinct vectors across 28,166 rows, carrying zero peptide information. They can only replace the HLA side, so the peptide side needs its own representation and the two sides are varied independently. Every arm uses an identical 60-unit sigmoid MLP, identical target transform s = 2^(-t0/thalf), identical loss, epochs and optimiser — only the input features change.

Paired difference from the baseline

Each arm is compared with the baseline at the same seed, so both see the same split; the per-seed differences are then averaged. This removes split-to-split variance, which is far larger than the effects being chased. The shaded band is the noise floor — anything inside it is not a result. Bars show mean ± SD of the paired difference.

Per-allele performance

A global correlation hides which alleles a model fails on. Each dot is one HLA allele; position is its per-allele Pearson correlation, averaged over seeds. Alleles are ordered by baseline performance.

What the model is actually looking at

Experimental peptide-HLA class I complexes from the PDB. The peptide sits in a groove formed by the HLA α1/α2 domains — the same 182 residues the dataset supplies as hla_seq. The B pocket anchors peptide position 2 and the F pocket anchors the C-terminus; those two pockets are what the Boltz-2 pocket embeddings were pooled over. Drag to rotate, scroll to zoom.
