Observed result

Frozen LigandMPNN features improved the supervised baseline in this fixed-budget experiment. With MSE, the combined peptide-independent features raised held-out-allele mean Spearman from 0.423 / 0.409 to 0.476 / 0.451 on all / nonzero rows. In the exploratory ranking-loss comparison, the corresponding improvement was 0.475 / 0.446 → 0.509 / 0.475. These are matched-loss comparisons; neither the best component ablation nor a random split was selected as the headline.

The structural score alone was weak: 0.130 / 0.122 for independent positions and 0.134 / 0.117 for autoregressive scoring. Conditional likelihood did not rescue zero-shot kinetics prediction. Native-template motif recovery and HLA-scrambling controls show meaningful context sensitivity, but shared-template transfer dilutes some allele-specific preferences. The evidence supports using pretrained features with a supervised head in this setting; it does not isolate a geometry-specific mechanism or establish a universal benefit across foundation models.

Autoregressive feature augmentation reached 0.493 / 0.453 with MSE and 0.506 / 0.471 with ranking loss. Its apparent MSE advantage over independent features is much smaller after zeros are excluded, and it reverses under ranking loss. Given the substantially larger scoring cost, these results favor the simpler independent-position features for this tested pipeline; they do not prove that biological position dependence is absent.

The proposed missing-clamp rationale also needs correction: six of the seven cited clamp positions already occur in the supplied pseudosequence. No empirical replicate ceiling can be estimated because the export contains no repeated allele–peptide pairs.

What changed with the loss

Pairwise ranking changes the label-only baseline from 0.423/0.409 to 0.475/0.446 (all/nonzero macro Spearman). The one-sided censoring surrogate gives 0.428/0.414. These objective comparisons use the same representation and fixed training budget. The assumed zero threshold remains unverified.

Random test rows reuse training peptides in 92.6% of cases. Nonetheless, this particular random split does not give higher mean per-allele performance than the peptide-disjoint split. The result demonstrates overlap, not a measured causal inflation in accuracy; the test compositions and eligible allele counts differ.
