Conclusion

Inverse folding did help — as an added feature

0.423 → 0.493
Feature, not predictor

Zero-shot likelihood barely ranks stability (0.13). Fed to a supervised head alongside the baseline, it lifts held-out-allele Spearman from 0.423 to 0.476–0.493.

0.475 → 0.509
Holds with ranking loss

With a pairwise ranking objective the baseline improves and structural features still add +0.03 (0.509 independent, 0.506 autoregressive).

745 s vs 45 s
Keep it simple

Autoregressive scoring is far costlier and adds little over independent features (Δ = 0.00 under ranking). Independent-position features win on value.

Scope: fixed-budget, single-seed comparison. Shows pretrained features transfer to unseen alleles — not a geometry-specific mechanism, nor a benefit for every foundation model.
